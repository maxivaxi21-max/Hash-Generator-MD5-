# 🔐 Hash Generator (MD5) — быстрый хеш для проверки целостности данных

> «MD5 — классика проверки целостности»

**Hash Generator (MD5)** — это набор консольных утилит для вычисления хеш-суммы MD5.  
Программа обрабатывает строки, файлы и потоковые данные, выводя результат в шестнадцатеричном или Base64-формате.  
(Примечание: MD5 не рекомендуется для криптографических целей, но широко используется для проверки целостности файлов.)

## 🚀 Особенности
- 🔢 Вычисление MD5 хеша для строк и файлов.
- 📁 Чтение данных из файла (с потоковой обработкой для больших файлов).
- ✍️ Ввод строки из командной строки или через STDIN.
- 🎨 Цветной вывод в терминале.
- 📤 Экспорт результата в текстовый файл.
- 🔄 Поддержка форматов: **hex** (по умолчанию) и **base64**.
- ⚡ Прогресс-бар для больших файлов (где реализовано).
- 🧪 Проверка целостности — сравнение хеша с эталонным значением.
- 📋 Пакетная обработка нескольких файлов (опционально).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки или встроенные модули).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `hashlib` (встроенный)               | `python hash_generator.py`              |
| Go         | `crypto/md5` (встроенный)            | `go run hash_generator.go`              |
| JavaScript | Node.js, `crypto` (встроенный)       | `node hash_generator.js`                |
| Java       | `java.security` (встроенный)         | `javac hash_generator.java && java hash_generator` |
| C#         | `System.Security.Cryptography`       | `dotnet run`                            |
| Rust       | `md5`, `hex` (crates)                | `cargo run`                             |
| Ruby       | `digest` (встроенный)                | `ruby hash_generator.rb`                |
| PHP        | `hash` или `md5` (встроенный)        | `php hash_generator.php`                |
